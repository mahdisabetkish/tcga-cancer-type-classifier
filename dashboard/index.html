Methodology & tech stack

Dataset

TCGA Pan-Cancer RNA-Seq (UCI ML Repository). RNA-Seq gene expression levels for 801 patients across five tumor types (breast, kidney, colon, lung, prostate), 20,531 genes per sample. Publicly available, no PHI.

Feature selection & preprocessing

Raw counts were log2-transformed, then the 60 most discriminative genes were selected with a univariate ANOVA F-test (SelectKBest). Features were standardized (zero mean, unit variance) before modeling. Reducing to 60 genes keeps the models fast to train, interpretable, and small enough to ship their weights to the browser for the live demo.

Models

  • Logistic Regression (scikit-learn): multinomial, L2-regularized linear baseline.
  • Random Forest (scikit-learn): 300 trees, used for feature-importance ranking.
  • Neural Network (PyTorch): 60 to 64 to 32 to 5 fully-connected MLP with ReLU activations and dropout, trained with Adam for 150 epochs.

All three train from scratch on a laptop CPU in well under a second (see the model comparison table). No GPU, no cloud compute required.

Client-side inference

For the live prediction panel, the trained Logistic Regression and Neural Network weights are exported to JSON and their forward passes re-implemented in about 30 lines of vanilla JavaScript. That means the entire dashboard (data, charts, and model inference) is fully static: no backend, no API calls, no server costs, and it keeps working even if the original training machine is off.

Limitations

This is a research and exploratory project, not a diagnostic tool. Gene identifiers in the source dataset are anonymized (gene_0 through gene_20530), so results should be read as a methodology exploration rather than a biological finding.
